# Project Walkthrough

This folder contains a complete walkthrough of the **Personalized Medicine for Lung Cancer: AI-Powered Drug Response Prediction and Personalized Drug Recommendation Framework** project.

The walkthrough provides a detailed explanation of the complete workflow, including data collection, preprocessing, feature engineering, model development, training, evaluation, and the final prediction pipeline.

---

## Available Files

| File                    | Description                                                                                                                  |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `Final Explanation.mp4` | A video walkthrough explaining the complete project architecture, methodology, datasets, models, and implementation process. |

---

## Topics Covered

* Project overview
* Dataset preparation
* NSCLC data preprocessing
* Drug representation using SMILES
* Mutation and gene expression analysis
* Feature engineering
* Task-aware feature extraction
* Embedding generation
* Graph Neural Network architecture
* Model training
* Drug response prediction
* Personalized drug recommendation
* Dashboard demonstration
