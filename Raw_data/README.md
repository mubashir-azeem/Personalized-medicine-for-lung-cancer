# Dataset Overview

The complete raw datasets used in this project are stored in a separate Google Drive folder because several files exceed GitHub's file size limits.

**Raw Data Folder:**

[Google Drive Dataset Repository](https://drive.google.com/drive/folders/1wPDx0PoiPiIfu5iIh4B1nccoOM-7aMxd?usp=sharing&utm_source=chatgpt.com)

## Available Datasets

| Dataset                       | Size         | Description                                                              |
| ----------------------------- | ------------ | ------------------------------------------------------------------------ |
| `CCLE_mutations.csv`          | 246.1 MB     | Mutation data collected from the Cancer Cell Line Encyclopedia (CCLE).   |
| `FINAL_NSCLC_EXPRESSION.csv`  | 41.9 MB      | Final NSCLC gene expression dataset after preprocessing and filtering.   |
| `FINAL_NSCLC_GDSC.csv`        | 4 MB         | NSCLC drug response dataset extracted from GDSC.                         |
| `GDSC_FULL_SMILES.csv`        | 16 KB        | Drug structures represented using SMILES notation.                       |
| `lung_expression_dataset.csv` | 53.8 MB      | Lung cancer gene expression dataset used for model development.          |
| `lung_metadata_filtered.csv`  | 50 KB        | Filtered metadata containing lung cancer cell line information.          |
| `NSCLC_expression_scaled.csv` | Dataset file | Normalized and scaled gene expression values used during model training. |

## Data Sources

* Cancer Cell Line Encyclopedia (CCLE)
* Genomics of Drug Sensitivity in Cancer (GDSC)
* DepMap

**Note:** All datasets can be accessed and downloaded from the Google Drive repository linked above.
